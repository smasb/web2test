# Pixel Pi-oneers website

A static HTML/CSS/JavaScript website ready for GitHub Pages.

## Files
- `index.html` — website structure and content
- `style.css` — layout, colours, responsive design and animations
- `script.js` — navigation, scroll reveals and interactive quiz
- `assets/` — team logo and images rendered from the two uploaded team portfolios

## Publish with GitHub Pages
1. Create a new GitHub repository (for example `pixel-pi-oneers`).
2. Upload **all** files and the `assets` folder, keeping the folder structure.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site. Your website URL will appear in the Pages settings.

## Customise
- Add your official email address in the `mailto:` link in `index.html`.
- Add your social media URLs when ready.
- Replace or add photographs in `assets/` and update the matching image paths in `index.html`.

The site does not need a backend, database or build process.

Open `index.html`, search for `YOUR_TEAM_HANDLE`, and replace it with the team's Instagram username. Keep the `assets` and `documents` folders in the repository root alongside `index.html`.
